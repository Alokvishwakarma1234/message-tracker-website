# Message Tracker — website

Showcase website for **Message Tracker**, an Android app that tracks expenses from bank SMS, fully offline (no internet permission).

Live: https://alokvishwakarma1234.github.io/message-tracker-website/

- Join the beta: https://play.google.com/apps/testing/com.messagetracker.app
- Google Play: https://play.google.com/store/apps/details?id=com.messagetracker.app
- Privacy policy: https://sites.google.com/view/message-tracker/home

Plain static site (HTML, CSS, JS) served by GitHub Pages from the `main` branch. No build step.
